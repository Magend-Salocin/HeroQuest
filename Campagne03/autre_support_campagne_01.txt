
Journal d’Agrain                                                                                        (Quête 2)
Support : Parchemin jauni, écrit en runes naines, partiellement brûlé. 
Contenu : "Le trente-septième jour de l’assaut. Zargon a corrompu mes hommes. Même Skulmar, mon capitaine le plus loyal, a succombé à ses promesses. Il brandit maintenant une épée noire, forgée dans les flammes du Chaos. Mes Cavaliers Fantômes, autrefois fiers, ne sont plus que des ombres obéissantes. J’ai scellé les Halls de Glace avec des runes de givre, mais je sais qu’il trouvera un moyen de les briser. Si vous lisez ceci, cherchez le Fer de l’Esprit. Il est caché là où le silence règne… sous les Passages que j’ai maudits moi-même. Que les ancêtres me pardonnent."
Indice : Le Fer de l’Esprit est caché dans les Passages du Silence (Quête 3)
Effet narratif : Si les joueurs trouvent ce journal, ils obtiennent un bonus de +2 pour détecter les pièges dans les Passages du Silence.
Journal d’un Prêtre Nain                                                                           (Quête 3)

Contenu : "Le rituel de purification fonctionne, mais à quel prix ? Nous avons utilisé le sang des traîtres pour sceller les portes, mais le Chaos a trouvé une faille. Les Plumes de Contrepoison, imprégnées du sang des rois, peuvent encore purifier les âmes corrompues. Elles sont cachées là où Kalos saigne… dans les cavernes où les murs eux-mêmes pleurent. Que les dieux protègent ceux qui viendront après nous. Nous avons échoué. Ne faites pas la même erreur."
Indice : Les Plumes de Contrepoison se trouvent dans les Cavernes Interdites (Quête 8). 
Effet narratif : Les joueurs peuvent utiliser ce journal pour localiser les Plumes sans déclencher de pièges dans les cavernes.

🎨 Carte Postale de Kalos
Format : Recto-verso (10x15 cm ou 15x10 cm, format standard carte postale).
________________________________________
🖼️ Recto : Vue de Kalos
Éléments visuels :
1.	Arrière-plan :
o	Une vue des ruines de Kalos au crépuscule, avec : 
	Des tours effondrées et des murs noircis (style gothique/dark fantasy).
	Une lueur violette (magie du Chaos) émanant des profondeurs.
	Des silhouettes de démons ou de guerriers squelettiques dans les ombres.
	Un ciel orageux avec des éclairs lointains.
2.	Détails :
o	En bas à gauche : Un symbole nain (marteau croisé avec une rune) gravé dans la pierre.
o	En haut à droite : Une chauve-souris ou un corbeau en vol (pour l’ambiance sombre).
o	Au centre : Le nom "Kalos" écrit en runes naines (style ancien et usé).
3.	Couleurs :
o	Noir, violet foncé, gris anthracite, avec des reflets dorés pour les runes.
Exemple de croquis :
Copier
[Ciel orageux avec éclairs]
      _______       _______
     /       \     /       \    (Tours effondrées)
    |   🏰    |   |   🏰    |
     \_______/     \_______/
       |   |
   [Lueur violette en bas]
   "KALOS" (en runes)
________________________________________
📜 Verso : Message du Mentor
Texte : "Merci d’avoir sauvé mon royaume. Les ombres de Kalos se souviennent de votre courage. Reviens quand tu veux… si vous l’osez. — Mentor, dernier gardien des secrets d’Agrain."
Style :
•	Écriture à la plume, légèrement tremblée (comme un vieux parchemin).
•	Ajoute une tache d’encre ou une empreinte de sang (rouge foncé) en bas pour le réalisme.
Exemple de mise en page :

🖌️ Comment la créer ?
Option 1 : À la main (pour un effet artisanal)
1.	Matériel :
o	Une feuille cartonnée (160 g/m² pour une carte postale).
o	Crayons noirs, aquarelle violette/noire, et encre dorée (pour les runes).
o	Un pinceau fin pour les détails.
2.	Étapes :
o	Dessine les ruines de Kalos au crayon, puis repasse à l’encre.
o	Ajoute des ombres avec de l’aquarelle diluée.
o	Écris le message au verso avec une plume ou un stylo-calligraphie.
Option 2 : Numérique (avec Canva ou Photoshop)
1.	Modèle prêt à utiliser :
o	Canva : Utilise un template de carte postale, cherche "dark fantasy" ou "ruines gothiques".
o	Éléments à ajouter : 
	Image de fond : Ruines gothiques (libre de droits).
	Police : "Old London" ou "MedievalSharp" (pour les runes).
	Filtres : Réduis la saturation et ajoute une teinte violette.
2.	Exemple de lien Canva :
o	Modèle Canva "Carte Postale Dark Fantasy" (recherche "gothic postcard").
o	Ajoute le texte et les symboles avec l’outil "Texte".
