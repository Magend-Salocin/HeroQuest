# 📜 Quête 4 : La Tour de Turekk Tor
Lieu : Tour personnelle de Melar, imprégnée de magie de la Terreur Ambiance : L’air est lourd, chargé d’une odeur de soufre. Des squelettes (anciens serviteurs de Melar) errent dans les couloirs. Une voix chuchote dans l’esprit du porteur du Talisman : "Avancez… Je vais vous aider."
Dialogue (Voix de Melar, via le Talisman – déguisée en Mentor) "Vous sentez un pouvoir de la Terreur derrière ce mur…" (la voix est douce, mais glaciale) "Cherchez le grimoire rouge. Il contient la clé pour briser les chaînes de Zargon."
________________________________________
🎯 Objectifs de la Quête
•	Explorer les appartements de Melar pour trouver des indices.
•	Découvrir le grimoire rouge (transforme les héros en orcs si lu).
•	Trouver un sort oublié (Éclair de la Terreur).
•	Obtenir une Carotte d’Enquête.
________________________________________
🔍 Événements Clés & Choix des Joueurs
1. Le Grimoire Rouge
•	Option 1 : Lire le grimoire (jet de Volonté) 
o	Réussite : Le porteur résiste à la transformation en orc.
o	Échec : Tous les héros (sauf le porteur) se transforment en orcs (2 PV, pas de magie, combat comme des orcs).
2. Le Sort d’Éclair
•	Le porteur gagne 1 Point d’Esprit et peut lancer Éclair (1 utilisation).
3. Les Squelettes Gardiens
•	Option 1 : Les combattre.
•	Option 2 : Les apaiser (jet de Religion) → "Agrain… nous attendions son retour." (ils laissent passer les héros).
________________________________________
🎲 Carotte d’Enquête (Fin de Quête)
Résultat	Type	Indice	Effet
1	Melar (Lore)	"Le grimoire rouge décrit un rituel de possession."	Permet de résister à une possession dans la Quête 6.
2	Squelette (Tactique)	"Les squelettes étaient les gardes personnels de Melar."	Bonus de +1 en Religion pour les apaiser dans la Quête 5.
3	Grimoire (Secret)	"Un grimoire bleu peut annuler la transformation en orc."	Déverrouille un objectif dans la Quête 5.
4	Zargon (Menace)	"Zargon a corrompu les appartements de Melar."	Affaiblit les sorts dans cette pièce.
5	Melar (Avertissement)	"Melar a laissé un piège : le grimoire bleu est caché dans le temple."	Indique l’emplacement du grimoire dans la Quête 5.
6	Sort (Récompense)	"Le sort Éclair peut briser les illusions de Zargon."	Permet de désactiver un piège magique dans la Quête 7.
