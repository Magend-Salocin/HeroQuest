# HeroQuest - campagnes

Ce dépôt rassemble les campagnes HeroQuest, leurs textes de quêtes, aides de jeu et ressources graphiques.

## Organisation

- `Campagne01/` : campagne de base et ses règles étendues. La structure Markdown y est en cours de mise en place.
- `Campagne02/` à `Campagne04/` : autres campagnes, supports et documents de travail. Ils ne sont pas modifiés dans cette première organisation.
- `_ressource/` : ressources communes, fiches et livres de quêtes.

Dans chaque campagne, le `README.md` local indique les sources et l'état de leur organisation. Les nouveaux fichiers Markdown servent de base de travail ; les TXT et DOCX existants sont conservés comme références tant que leur contenu n'a pas été validé et migré.

## Impression

Le format de travail recommandé est Markdown. La cible d'impression est un PDF, généré à partir des fichiers Markdown validés. Les DOCX existants peuvent servir de référence visuelle pour les styles, mais ne sont pas la source éditoriale. Avant une impression complète, vérifier les tableaux, sauts de page, marges et caractères accentués dans une exportation test.

## Conventions

- Conserver le français et les noms propres tels qu'ils apparaissent dans les sources, sauf correction validée.
- Distinguer règles, contenu de quête, conséquences de campagne et suivi de partie.
- Signaler les contradictions entre sources au lieu de les résoudre par supposition.
- Ne pas supprimer les originaux lors d'une migration sans validation explicite.
